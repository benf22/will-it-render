Body font options — pick a number

1 — Inter

Abstract

Text-to-video diffusion models generate increasingly realistic videos, yet often fail to render all objects requested by the prompt, particularly as the number of objects grows. Existing approaches typically define hand-crafted objectives over cross-attention maps, relying on indirect attention statistics rather than whether the model ultimately renders a requested object.

We propose AttnSteer, a learned attention-steering model that predicts object rendering directly from intermediate cross-attention and contains only 37k parameters.
