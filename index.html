Abstract

Text-to-video diffusion models generate increasingly realistic videos, yet often fail to render all objects requested by the prompt, particularly as the number of objects grows. Improving such fine-grained adherence through training requires substantial video supervision, motivating inference-time methods that steer intermediate diffusion latents. Existing approaches typically define hand-crafted objectives over cross-attention maps, relying on indirect attention statistics rather than whether the model ultimately renders a requested object.

We propose AttnSteer, a learned attention-steering model that predicts object rendering directly from intermediate cross-attention. AttnSteer is trained entirely on the generator's own trajectories using automatically obtained detector labels and contains only 37k parameters. At inference time, its predictions define differentiable objectives for steering object presence; the same framework also extends to frame-level temporal control. AttnSteer improves all-objects accuracy over the strongest baseline at comparable video quality.

Method

Inference

At inference time, AttnSteer's predictions define differentiable objectives for steering object presence. The video latent is optimized while the generator stays fixed. For multi-object prompts, independent per-object updates can conflict: we filtering out objects which are likely to be rendered, for the remain objects we normalize each ones gradient, and aggragate all objects' gradients while suppress locally opposing contributions.

AttnSteer Training

We train a tiny model - AttnSteer to predict whether each requested object will be rendered. We use per-step, per-layer, per-head cross-attention features from the frozen generator. Labels come from detectors run on the generator's own final videos.

User Study

To confirm the improvement is visible to people, we ran a paired human-preference study on LTX-2 and Wan 2.1, comparing AttnSteer against Attend-and-Excite on object presence, photorealism, and motion smoothness. 37 volunteer annotators completed 622 clip judgements. AttnSteer is preferred on every question and both backbones. The largest margin is object presence on Wan 2.1 (73.9% of decisive votes); photorealism and motion smoothness — included as quality guardrails — also come out in our favor (58–67%).

Single-Object Guardrail

We evaluate on 79 VBench object_class single-object prompts as a guardrail: with only one requested object, backbones already succeed on most clips, and the goal is to verify that steering does not harm this easy regime. AttnSteer in fact improves single-object presence on LTX-2 under both detectors, while leaving VBench quality unchanged.

Temporal Control

The same learned objective applies frame by frame, so it can control when an object appears. On single-object prompts, where an object must enter at a prescribed time, AttnSteer raises specificity from 31.2% to 52.6%, meaning fewer frames before the requested onset are wrongly filled. Temporal alignment (t-IoU) rises from 40.6% to 45.0%, and VBench quality is unchanged (74.7 vs. 75.1).
